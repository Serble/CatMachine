# Example Projects
Here are some examples of functional projects written in CatASM or Catnip.
Some highlights include:

### Snake
A tiled snake game with animated apples using the RaylibPPU in tiled mode.

### Snake 2
A tiled snake game with better looking snake body, a menu, and better scaling collision checking.

### Platformer Catnip
A very simple platformer that allows jumping, implements velocity, dying, and map loading. Uses the RaylibPPU
tiled mode.
